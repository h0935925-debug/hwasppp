# GiftBox AutoFill

مشروع Android تجريبي لحفظ بعض اختيارات المستخدم وإعادة استخدامها عند ظهور سؤال مطابق.

## التشغيل
1. افتح المشروع في Android Studio أو ارفعه إلى GitHub.
2. فعّل خدمة GiftBox AutoFill من إعدادات إمكانية الوصول.
3. اسمح بالظهور فوق التطبيقات حتى يظهر الزر العائم.
4. افتح صفحة استبيان في المتصفح واضغط «تعلم» ثم اختر الإجابات بنفسك.
5. في محاولة لاحقة اضغط «تشغيل». أوقفه فورًا إذا لاحظت اختيارًا غير صحيح.

## حدود مهمة
- هذا نموذج أولي وليس ضمانًا للتوافق مع كل المتصفحات أو صفحات GiftBox.
- المتصفح قد لا يكشف شجرة عناصر صفحة الويب لخدمة إمكانية الوصول، وبعض عناصر الاستبيان ديناميكية.
- التعرف على السؤال والإجابة مبني على نصوص العناصر الظاهرة، وقد لا يلتقط العلاقة الصحيحة بين السؤال والاختيار في كل تصميم.
- لا يتجاوز OTP أو رقم الهاتف أو CAPTCHA، ولا يرسل الاستبيان نيابة عنك. راجع الإجابات قبل الإرسال.
- البيانات التعليمية محفوظة محليًا في SharedPreferences على الجهاز. حذف بيانات التطبيق يمسحها.
- استخدمه فقط لإعادة إدخال إجاباتك الحقيقية والمتسقة، وبما يتوافق مع شروط المنصة وقواعد البحث.

## البناء
يتطلب JDK 17 وAndroid SDK 35 وGradle 8.9 أو أحدث متوافق مع Android Gradle Plugin 8.7.3.
